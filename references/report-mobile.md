# 小屏汇报

读者在手机或聊天软件里看汇报时使用。内容、图表、载体和发出前的检查仍按[汇报](report.md)，这里只写小屏上不同的地方。

读者的处境：碎片时间，单手，随时被打断。层次不变，默认展开得更少。

- 默认展开到结论，依据点开看。
- 第一屏只放结论、一个最强的数和要读者做的事。
- 单列，一屏一件事。不出现并排的长文。
- 文字对比至多两项并排，数字表可多几列；更多改成逐项卡片。确实要横向滚动的表，露出半列提示还能滑。
- 一图占满宽，只画一个系列。字按缩小后仍看得清来定，不出现要放大才看清的图。
- 每段不超过三行。难的内容改短，不是缩小。
- 回复点一下或回一个词；点按区不小于 44 点。
- 聊天软件放不下的内容给链接，消息里只留结论和要读者做的事。
- 页面渲染出来按手机宽度看过。
