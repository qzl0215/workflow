# 修复失败

## 何时进入

出现 bug、测试/构建失败、性能或行为异常、空结果、flaky 状态、真实验收失败，或同一实现路径连续失败时进入。证据已经直接指向单点 typo、局部条件错误或局部语法错误，且未被共享或复制时，可局部修复并做相称验证，不启动同源影响面审计、不新增项目文档。

## 已知输入

- 预期、实际、影响面、最小复现和失败时间；
- 错误、日志、输入、环境、最近变更、调用边界与 source fingerprint；
- 已验证/已排除假设、尝试过的手段和相邻回归；
- 候选根因机制、可能被破坏的系统不变量、共享消费者和复制模式；
- 可用观测点、权限、风险和安全回退方式。

## 深度判断

先区分单点错误、多处复制的错误逻辑、共享底层机制错误、系统不变量缺失、环境/数据/外部依赖问题，以及只有症状相似但机制不同的问题。能够稳定复现且影响局部用 H1；跨层、共享机制、flaky、数据损坏或多次失败用 H2；生产、安全、不可逆或根因跨系统用 H3。诊断深度由不确定性和风险决定，不由错误表面大小决定。

## 核心动作

1. **写出预期**、实际、影响面和最小复现；不能复现时先增加可观测性。
2. **收集错误**、完整日志、输入、环境、最近变更与调用边界，分开事实和假设。
3. 沿数据/控制流**向上追踪**第一个错误状态，不在末端症状堆补丁。
4. 一次验证一个**可证伪假设**；用最小实验、对照组和条件等待，不增加固定 sleep 掩盖竞态。
5. **先分类**：判断它是单点 typo/局部条件错误、多处复制逻辑、共享机制错误、不变量缺失、环境/数据/外部依赖，还是仅表象相似。证据只指向未共享的单点错误时走快速通道，不机械升级。
6. **识别不变量**：当第一个错误状态位于公共边界或共享机制时，写清所有相关路径本应共同成立的规则，以及当前机制如何破坏它。
7. **审计同源影响集**：同源 Bug 必须共享同一根因或违反同一不变量，能被相同或等价反例证明，并可由同一个正确边界上的处理自然覆盖。通过定向搜索、调用链/数据流检查或最小实验检查共享机制的消费者、同类数据/状态路径和复制模式；记录搜索边界与停止依据，不默认全仓扫描。只有症状相似而根因不同的位置排除在当前范围外，按独立缺陷处理。
8. **按证据确定修复范围**：依次判断根因是否相同、相同或等价失败能否复现、底层处理能否自然覆盖、不处理是否产生真实错误/安全风险/重复返工，以及回归风险和验证成本是否可控。
   - 根因相同且影响已证实：纳入当前处理；
   - 根因相同但修改风险高：拆成有退出条件的分阶段处理；
   - 只有症状相似：明确排除；
   - 证据不足：先做最小实验；仍无法证明时不得直接扩大改造，记录残余风险、验证条件或独立 side task；
   - 与当前机制无关的优化：不得借机纳入。
9. **修复根因**的最小完整表面：优先在正确公共边界恢复不变量，让已证实同源消费者自然受益，而不是在多个末端堆补丁；避免无关重构。若底层变更涉及高风险、不可逆迁移或广泛兼容影响，允许按顺序进行安全止血、固定复现和退出条件、审计影响面、修复或迁移底层机制、验证纳入的消费者、删除临时补丁；临时缓解不得描述为根因修复完成。
10. 先**重跑复现**，再跑已纳入同源路径、相邻回归和更高层验收；flaky 问题必须证明等待条件和稳定次数。
11. 第一次失败定位证据；第二次换本质不同观察点或实现；第三次列假设、反转假设并扩大源码/文档证据，必要时请求决策。

## 写入真源

单点问题只记录相称的复现、处理和验证。非单点问题在现有 `progress.md` 的按需根因闭环区记录当前症状、最小复现、已证实根因、被破坏的不变量、同源影响集及检查方法、已纳入修复、明确排除及原因、尚未证实的风险、修复边界与停止依据、验证证据；没有持久真源的标准任务留在现有任务回执，不为此新建文件。新的稳定项目事实补回原代码、测试、配置或 README owner；临时日志和实验脚本在证据记录后移除，不建独立故障报告或知识库。

## 停止 / 通过

单点问题在局部原因得到证明、复现转绿且相称验证通过后快速结束。共享机制或不变量问题只有在根因能解释现象、正确边界恢复不变量、已证实同源影响得到处理、相邻回归与上层验收通过，并记录审计边界、停止依据和残余风险后才闭环；最小化对象是消除已证实根因的最小完整修复，不是最小 diff。只能消除症状、只完成安全止血或不能解释根因时保持未完成，除非用户明确接受有证据的临时缓解与退出条件。

## 失败回路 / 能力缺口

事实表明不是 bug 时返回产生缺口的上游动作。同一阻断重复出现时保留排除证据并换工具、观察点或路线。危险诊断、生产写入或新权限必须停止并请求授权；缺少日志/环境时写具体 blocker，不让用户笼统“手动看看”。
