# 页面设计

做、改或评审页面时，从读者打开后要辨认的对象、要完成的动作开始。短提示和已有材料足以确定这些，就直接制作。改现有页面沿用真实源码、组件和预览入口。只画一张数据图、不做整页时，直接看下面的“画数据图”一节。

## 用途决定主画面

| 读者要做什么 | 怎样排内容与组件 |
|---|---|
| 看方案差别、做决定 | 把同一对象放入各方案，同维度对齐。比较数字共用刻度，比较视觉方向用同一内容做并列样张。把依据和代价放在对应差异旁。 |
| 看变化、探索数据 | 连续时间优先画折线，离散观测可用同轴柱。切换对象时保留可比较的尺度，图、单位、数值和说明一起更新。见[可操作的观测图例](../templates/explorer.html)。 |
| 追踪关系或流程 | 从一个具体对象画通主路径，再展开分支、断点和详情。节点、连线和方向要能读懂；颜色已表示类型时，用线型和文字表示状态。 |
| 试用产品 | 把主要空间交给正在操作的对象。做通一条完整路径，例如选中对象、修改、看到结果、返回。 |
| 看懂概念或作品 | 选能说明对象的实物、图解或样张，用近处标注连接解说。按读者要辨认的细节决定图幅、留白和局部放大。 |

决策汇报页和战略屋有[版式库](../templates/pages.html)。从顶部索引按用途取需要的片段，例如方案用 options、进度用 status、战略屋用 house。保留真实内容的维度和证据，底座接入目标项目主题。

## 形成页面风格

沿用项目的品牌、字体和交互习惯。新页面从题材和主对象取视觉基调。数据页把宽度留给主图与对齐的数列，阅读页收窄文字列。靠对齐和留白分组，独立操作区才需要容器。把标题、正文、单位与来源拉开层级，数字比较用等宽数字。

把画布、文字、分隔和强调映射到主题变量。数据图按下面的“画数据图”一节画。同一含义贯穿图例、图形与选中态，状态同时有文字或形状。深浅主题分别核对对比度。

关系图需要已知关系或步骤；演示用的虚构数据明确标注。控件随操作更新对应内容，能用键盘操作且焦点可见，空结果有恢复入口，减少动效后仍能辨认状态。

## 画数据图

聊天、汇报和页面里的数据图都按这里画。本机装有 `dataviz` 时调用它选图和校验配色。动笔前先定读者看完要记住哪个数、它是好是坏，再选形式，最后才定颜色。

| 要点 | 规则 |
|---|---|
| 结论先出 | 标题写结论句。读者要记住的数单独放大，带分母或参照，如“22 次，占 73 次的 30%”。只有一个数要讲时只给数字，不画图 |
| 选形式 | 比大小用同一基线的横条；看一个整体怎么分、不超过 6 段时用一根分段条；看随时间变化用折线；要逐个比较各部分或超过 6 段时，用横条或表 |
| 颜色只说一件事 | 结论落在某一段或某一条上时，只给它上强调色，其余用灰。数量用同一色相的深浅，有先后的分档按顺序由浅到深；类别没有先后时才换色相；有明确中心值的偏离才用两色发散，中心用灰 |
| 颜色含义 | 绿红只表示好坏，不当普通类别色；要读者警惕的结果不用绿色 |
| 标签贴着图形 | 名称和数写在对应色块里或正下方，与色块同宽对齐。不超过 4 个系列时不另放图例；必须放时排成一行，顺序同图形 |
| 顺序 | 有天然先后的（快到慢、小到大、早到晚）保持先后；没有先后的按大小排 |
| 分档 | 分档界限是人定的，先看分出来能否拉开差别。耗时、等待类优先给中位数和九成请求的耗时（P50、P90），或对目标的达标率 |
| 细节 | 文字用正文色，不用系列色；相邻色块留 2 像素空隙；图和明细共用一份数据，图下写单位、口径、来源和时间 |

画完截图只看图：三秒内说不出结论数字和它是好是坏，就回到第一行重做。

## 写文案

准确 > 清晰 > 简洁 > 美感，冲突时按这个顺序取舍。好文案存在感低：读者几乎注意不到它，却能顺利看懂对象、找到信息、完成操作。

- 只写读者看到的对象、能做的操作和真实状态。数字、数量和限制与页面内容和源码一致，没测的标出来。
- 用读者的词，同一事物全页一个叫法。链接和按钮说清点了去哪、会发生什么；去同一处就用同一说法。
- 标题说明下面是什么。不写口号、对仗句、对页面设计的自评或写给 AI 的话。
- 文字在解释“这不是……”时，先改图或交互，再删掉这句。
- 报错和空结果说清发生了什么、读者下一步做什么，为此长一点也值。
- 已经做到这些的文案不改。

## 有参照时，从样页提炼做法

选与目标阅读动作相近的样页，截首屏并操作一次。看主体占多少空间、哪些元素成组、颜色各代表什么、操作后哪些区域联动。需要核对时用 REA 读 DOM，结合浏览器计算样式和截图。普通生成可直接使用已提炼的做法。

把观察写成换材料也成立的约定。例如“切换对象时固定坐标轴，突出选中曲线，同步右侧读数”。用目标项目的内容和品牌重做，业务数据、文案和标识留在原样页。反复制作同类页面时，把已经验证的约定放回项目现有主题或组件。

## 打开成品验收

在浏览器用桌面和手机宽度打开交付文件，检查首屏主次、长标签、焦点和整页溢出。窄屏保留图内文字的正常字宽，关键刻度和读数按实际显示约 12 像素起排。空间紧先减刻度或把标签放入 HTML；用适配视口的坐标绘图，避免整张桌面 SVG 连字一起压扁或缩小。宽关系图可在画布内平移。操作主要控件，拿一组已知数据核对变化；只读页面检查读者要找的信息。逐条核对文案里的数字和说法，点一遍链接，看文字与结果是否一致。对标时同尺寸并排看首屏和操作后状态；要复用做法时再换一份材料。离线 HTML 断网打开，检查图片、字体回退与主要交互。
